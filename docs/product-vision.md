# Product Vision

Rift Architect exists to turn a League of Legends composition into a clear strategic briefing.

## Vision

The product should help the user answer three questions fast:

1. What composition did I build?
2. How do I win with it?
3. What must I avoid so the plan does not collapse?

## What the product is not

- It is not a generic champion encyclopedia.
- It is not a rival comparison tool first.
- It is not a wall of stats.
- It is not a new screen for every idea.

## Current product direction

- Analyse the user’s own composition first.
- Explain the plan in coach language.
- Show the critical dependencies and risks.
- Offer practical draft help when the composition needs it.
- Keep the interface short, readable and stable.

## Success criteria

The app is successful when it can be used in a few seconds to understand:

- identity;
- win condition;
- tempo;
- execution risk;
- contingency;
- bans;
- last-pick needs.
