# Product Vision

## What Rift Architect is

Rift Architect is a compact League of Legends composition tool built from `Draft Pool.xlsx`.

It helps the user understand a draft in seconds, not minutes.

## What it is not

- It is not a stat tracker.
- It is not a meta site.
- It is not a rival analyzer.
- It is not a long-form coaching tool in the main screen.

## Core principles

1. The Excel is the source of truth.
2. The engine summarizes; the IA explains.
3. The main screen must be understandable in under 10 seconds.
4. Information must be concrete, short, and consistent.
5. No unnecessary text, scores, or visual noise.

## Information budget for the main analysis

- 1 primary identity.
- Up to 2 secondary identities.
- Up to 4 strengths.
- Up to 3 weaknesses.
- 1 tempo statement.
- Up to 3 short plan actions.

## UX rules

- Show the most important information first.
- Keep each block short and scannable.
- Avoid duplicate concepts.
- Prefer tokens and labels over paragraphs.
- Keep the same structure on PC, tablet, and mobile.

## Role of the future IA

The IA will not invent the composition analysis.
It will read the analysis object and explain it in natural language.

## Design goal

A user should be able to select five champions and understand the draft at a glance.
