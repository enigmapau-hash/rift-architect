# Strategic Profiles

Strategic profiles are reusable families that help the engine map a composition to a clearer plan.

## What they do

- Translate champion identities into higher-level plans.
- Group similar play patterns into reusable families.
- Help the engine reason about objectives, tempo and execution shape.
- Support bans and last-pick guidance.

## Current role in the product

The strategic profile layer now sits between raw champion data and the visible narrative. It helps answer questions like:

- Is the plan dive, front-to-back, poke, pick, splitpush or control?
- What does this composition need to execute safely?
- Which champions are the critical anchors?
- Which profiles become liabilities when the draft is incomplete?

## Current rule of thumb

A profile is useful when it improves reasoning more than it increases complexity.
